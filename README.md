# Kallen plugins for Claude and ChatGPT (draft, not published)

Slash commands for Claude that run Kallen's strategist tools over the Kallen MCP connector (`https://kallen.ai/mcp`):

| Command | Runs |
| --- | --- |
| `/hooks [topic] [tracked]` | `top_hooks` |
| `/formats [topic] [tracked]` | `top_formats` |
| `/topics [tracked]` | `top_topics` |
| `/recap <creator>` | `get_creator_recap` |
| `/next-video [topic] [tracked]` | `top_topics` then `get_idea_brief` |
| `/remix <Kallen ID>` | `get_reference_evidence mode=blueprint` |

The commands are the same text as the server's MCP prompts. ChatGPT and other MCP clients get those prompts straight from the connector, with no plugin. The user's own AI writes the ideas from what it knows about the user; Kallen stores nothing about them.

## Layout

- `.claude-plugin/marketplace.json`: makes this folder a plugin marketplace, so it can be added from a public repo.
- `kallen/.claude-plugin/plugin.json` and `kallen/.mcp.json`: the plugin and its connector.
- `chatgpt/kallen/`: the same skills and connector in OpenAI's portable plugin format, with the ChatGPT listing and review cases. Zip its contents for platform.openai.com/plugins.
- `kallen/skills/*/SKILL.md` and `chatgpt/kallen/skills/*/SKILL.md`: generated by `node scripts/build-plugin.mjs` in `projects/kallen/access` from `server/mcp-prompts.mjs`. Don't edit them by hand; `--check` and a test catch drift.

## Distribution (needs Isaac's OK; nothing has been published)

1. **Public repo:** copy this folder to a public GitHub repo, for example `kallen-ai/plugins`. Users then run `/plugin marketplace add kallen-ai/plugins` and `/plugin install kallen@kallen`.
2. **Directory listings:** the connector and plugin in Claude's directory, and the ZIP in ChatGPT's. Kit and blockers: `docs/mcp/directory-listing.md`.
